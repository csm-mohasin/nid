যেভাবে কাজ করবে

  1. উপরে ইউনিয়ন ও ওয়ার্ড বেছে নাও।
  2. ভোটার লিস্টের পেজের ছবি তুলো (ফোনের ক্যামেরা/Gemini অ্যাপ দিয়ে)।
  3. Gemini-কে নিচের prompt + ছবি দাও, ও একটা JSON রিটার্ন করবে।
  4. সেই পুরো JSON কপি করে নিচের বক্সে পেস্ট করো, "পার্স করো" চাপো।
  5. এন্ট্রিগুলো এডিট স্ক্রিনে আসবে — ভুল থাকলে ঠিক করে Save করো।
